# Чек-лист главного экрана

Ручная проверка главного экрана — после изменений в `filelist/` и `navigation/`. Формат: действие → что должно быть. Номера сквозные — на них удобно ссылаться («сломан 27»); новые пункты получают следующий свободный номер в своём разделе.

Что ещё не проверено руками или задумано поменять при редизайне — помечено **(уточнить)**.

Часть пунктов проверяют UI-тесты — список в [testing.md](testing.md), «Что покрыто»; если тесты зелёные, их можно не проверять руками.

## Открытие и навигация

1. Запуск из лаунчера → открыта папка из настройки «Папка по умолчанию» (`FILE_LIST_DEFAULT_DIRECTORY`).
2. Тап по папке → вход в неё; хлебные крошки и подзаголовок («N папок, M файлов») обновились.
3. Системное «Назад» в подпапке → на уровень выше. В корне хлебных крошек → снизу панель «Закрыть mftlrs?» (`ExitConfirmation.kt`): «Закрыть» — `finishAndRemoveTask()`, приложения нет в недавних, при следующем запуске открыта папка по умолчанию; «Свернуть» — приложение в фоне, при возврате та же папка; «Отмена», свайп вниз, тап по фону или «Назад» — панель закрыта. В режиме выбора файла для другого приложения панели нет — сразу выход.
4. Зайти на 3 уровня вглубь, «Назад» дважды → крошки справа от текущей остались видны; тап по ним возвращает вглубь (`TrailData`).
5. Прокрутить длинную папку, войти в подпапку, «Назад» → позиция прокрутки восстановлена.
6. Меню → «Вверх» → на уровень выше; если открыт поиск — он закрывается.
7. Меню → «Перейти к…» → диалог с текущим путём; ввод другого пути → переход.
8. Меню → «Открыть в новом окне» → отдельная задача в «Недавних» с той же папкой.
9. Тап по ZIP → открыт как папка; в крошках — путь до архива и внутри него; «Назад» выходит из архива.
10. Ярлык папки на рабочем столе → экран открыт на этой папке, история с нуля.

## Состояния списка

11. Пустая папка → пустое состояние, подзаголовок «Пусто».
12. Папка без доступа (например, `/data`) → текст ошибки по центру, подзаголовок «Ошибка».
13. Ошибка при перечитывании уже показанного списка → тост с ошибкой, список остаётся.
14. Медленная папка (SMB, большой архив) → индикатор загрузки по центру, подзаголовок «Загрузка…».
15. Свайп вниз → перечитывание, индикатор Material 3 сверху. То же — меню → «Обновить».
16. Создать или удалить файл в папке из другого приложения → список обновился сам (`PathObserver`).

## Вид и сортировка

17. Меню → «Вид» → список и сетка. В сетке колонок = ширина экрана / 180 dp, минимум 2; при повороте пересчитывается.
18. Сортировка по имени, типу, размеру, дате; «По возрастанию»; «Сначала папки» → порядок меняется, галочки в меню верные.
19. «Для этой папки» → вид и сортировка запоминаются только для неё; в другой папке — общие.
20. Меню → «Показывать скрытые» → файлы с точкой появляются и пропадают без перезагрузки папки.
21. Настройка обрезки длинных имён (в начале, в середине, в конце, бегущая строка) → применяется сразу.
22. Быстрая прокрутка: справа полоса с ручкой, видна всегда, пока список длиннее экрана; ручку можно тянуть, тап или проведение по полосе — ручка прыгает под палец; подсказки с буквой нет. Долгое нажатие на элемент под полосой открывает его меню; в сетке и списке, в конце списка ручка у нижнего края.

## Элемент списка

23. Миниатюры: картинки, видео, PDF; у APK — иконка приложения. Пока миниатюры нет — иконка типа.
24. Папка `Android/data/<пакет>` → значок приложения поверх иконки папки.
25. Значки (badges): симлинк, битый симлинк, зашифрованный файл.
26. В режиме списка у файла вторая строка «дата · размер», у папки её нет.
27. Долгое нажатие на элемент или правая кнопка мыши → контекстное меню у места нажатия (у края экрана — сдвинуто внутрь); кнопки ⋮ у элементов нет. Видимость пунктов:
    - «Выбрать» — первый; нет у уже отмеченного и у файлов, которые нельзя выбрать в режиме выбора файла для другого приложения;
    - «Вырезать», «Удалить», «Переименовать» скрыты на файловой системе только для чтения;
    - «Копировать» внутри архива называется «Извлечь»;
    - «Извлечь» — только у архивов; «Архивировать» скрыт внутри архива;
    - «В закладки» — только у папок;
    - всегда: «Открыть с помощью», «Поделиться», «Копировать путь», «Создать ярлык», «Свойства».
28. Каждый пункт меню файла выполняет своё действие; «Открыть с помощью» → выбор приложения, в списке также «Редактировать» и «Открыть как…».

## Выделение

29. Кнопка с флажком справа от поиска → режим выбора: поверх верхней панели с затуханием — панель «Выбрано: 0»; в списке слева у строк появляются квадратные флажки, строки плавно сдвигаются вправо; в сетке — флажок на подложке в левом верхнем углу превью, виден и на картинках. Тап по элементу не трогает иконку отдельно: выделения тапом по иконке больше нет. При выборе файла для другого приложения без множественного выбора кнопки нет.
30. В режиме выбора: тап — отметить или снять, папка не открывается; снята последняя отметка — режим остаётся, «Выбрано: 0».
31. Контекстное меню и режим выбора:
    - вне режима: «Выбрать» в меню → режим выбора, элемент отмечен;
    - после «Выбрать» меню закрывается на месте, не съезжает;
    - в режиме, на неотмеченном: меню этого элемента, «Выбрать» отмечает его;
    - в режиме, на единственном отмеченном: обычное меню этого элемента, без «Выбрать»;
    - в режиме, на одном из нескольких отмеченных: меню для всех выделенных — пока только неактивный пункт «Выбрано: N» **(уточнить:** пункты меню для всех выделенных — [todo.md](todo.md)**)**;
    - то же правой кнопкой мыши (мышь или тачпад) — проверяется только руками.
32. «Выбрать все» (в меню экрана и на панели выделения) → режим выбора, отмечены все видимые файлы.
33. Пункты панели выделения:
    - ничего не отмечено — только «Выбрать все» в ⋮;
    - «Вырезать» и «Удалить» скрыты, если хоть один файл на ФС только для чтения;
    - «Копировать» → «Извлечь», если все файлы внутри архива;
    - «Извлечь» — если все выделенные — архивы;
    - «Архивировать» скрыт, если текущая папка только для чтения;
    - «Поделиться».
34. «Назад» или крестик на панели → режим выбора выключен, отметки сняты, флажки пропали.
35. Поворот экрана → режим выбора и отметки сохранены.
36. Действие над выделенными (вырезать, копировать, удалить, архивировать, поделиться) → отметки сняты, режим выбора выключен. Действие из меню неотмеченного элемента в режиме выбора режим не выключает, если остались отметки.

## Вставка

37. Вырезать или копировать → снизу панель «Перемещение: N» / «Копирование: N» / «Извлечение: N».
38. Перейти в другую папку → панель остаётся; «Вставить» (или «Извлечь сюда») → операция в фоне, уведомление, панель исчезла.
39. Папка только для чтения → кнопка «Вставить» неактивна.
40. Крестик на нижней панели → буфер очищен, панель исчезла.

## Открытие файлов

41. Тап по картинке → просмотрщик; листаются соседние картинки в порядке сортировки на экране.
42. Тап по APK → по настройке «Действие для APK»: установить, открыть как архив или спросить.
43. Тап по другому файлу → внешнее приложение; файл внутри архива сначала извлекается во временный.
44. Нет приложения для типа → тост, без падения.

## Создание

45. «+» слева от поиска → меню «Файл», «Папка» с иконками → диалог имени → файл или папка создаётся в текущей папке. Тап мимо меню → меню закрывается. FAB внизу справа на тап не реагирует (нет ripple), список под ним не нажимается.
46. Существующее имя в диалоге → ошибка в поле, кнопка неактивна.
47. «Назад» при открытом меню «+» → меню закрывается, навигации нет.

## Поиск

48. Иконка поиска → поле ввода; результаты через ~1 с после последней буквы; Enter — сразу.
49. Пока поиск открыт → пункт «Вид и сортировка» в меню скрыт; результаты не пересортировываются.
50. Закрыть поиск → обычный список текущей папки.
51. Тап по папке в результатах → переход, поиск закрыт.
52. Поворот экрана при открытом поиске → поле и запрос сохранены.

## Меню экрана

53. «Поделиться» (текущая папка), «Копировать путь», «Открыть в терминале» (только локальная ФС), «Добавить в закладки» (тост), «Создать ярлык».

## Выбор файла для другого приложения

Как вызвать: в любом приложении «Прикрепить файл» или «Сохранить как» → выбрать mftlrs.

54. Открыть файл (`GET_CONTENT`, `OPEN_DOCUMENT`) → заголовок «Выберите файл»; меню файла без «Вырезать» и «Копировать»; файлы с неподходящим MIME-типом неактивны, папки открываются.
55. Тап по подходящему файлу → экран закрыт, приложение получило файл.
56. С множественным выбором → кнопка с флажком на панели, можно отметить несколько, кнопка «Выбрать» (✓) на панели выделения; без него → кнопки с флажком нет, «Выбрать» в контекстном меню отмечает только один.
57. Сохранить файл (`CREATE_DOCUMENT`) → снизу поле имени, имя предзаполнено, выделено без расширения, поле в фокусе, клавиатура открыта, панель над клавиатурой; «Сохранить» (или Enter):
    - пустое или недопустимое имя → тост;
    - имя существующего файла → диалог замены;
    - новое имя → экран закрыт, файл передан.
58. Тап по существующему файлу в режиме сохранения → имя подставлено в поле, диалог замены.
59. Выбор папки (`OPEN_DOCUMENT_TREE`) → снизу «Открыть «<имя папки>»»; кнопка возвращает текущую папку.
60. Крестик на нижней панели в режиме выбора → экран закрыт без результата.

## Разрешения

61. Первый запуск без доступа ко всем файлам (Android 11+) → диалог-объяснение → системные настройки → после возврата список перечитан.
62. Отказ в диалоге → затем запрос уведомлений (Android 13+); повторно в этой сессии не спрашивает.

## Окно и система

63. Отступы под системные панели (edge-to-edge): фон верхней панели уходит под строку состояния, заголовок — ниже неё; список уходит под панель навигации, последний элемент не закрыт навигацией, FAB и нижней панелью; FAB — над панелью навигации, а при нижней панели — над ней; нижняя панель — над панелью навигации. В ландшафте с панелью навигации сбоку ничего под неё не заходит.
64. Поворот экрана в любом состоянии (выделение, вставка, поиск, режим выбора, введённое имя файла) → состояние сохранено. Открытые меню панели («+», «Вид и сортировка», ⋮) при повороте закрываются.
65. Физическая клавиатура: Ctrl+L «Перейти к…», Ctrl+R «Обновить», Ctrl+A «Выбрать все», Ctrl+H «Показывать скрытые»; при выделении — Ctrl+X, Ctrl+C, Ctrl+A; при панели вставки — Ctrl+V (`onKeyShortcut`). **(уточнить:** нужно ли это вообще**)**
70. Светлая и тёмная тема (настройка ночного режима) → все части экрана в цветах темы: панели, меню, FAB, нижняя панель, полоса прокрутки.

## Боковая панель

После новой навигации — проверять, что всё это достижимо из неё. **(уточнить** при редизайне**)**

66. Хранилища, тома SD и USB, «Добавить хранилище» → переход в корень, история сброшена.
67. Стандартные папки, закладки → переход.
68. FTP-сервер, Настройки, О программе → открываются.
69. Текущая папка подсвечена в списке навигации.
71. Телефон: значок ☰ и свайп вправо с любого места экрана открывают панель; «Назад» её закрывает.
72. Планшет в альбомной ориентации (`sw600dp`): панель постоянная, во всю высоту слева от экрана; ☰ прячет и показывает её, состояние запоминается.
73. Долгое нажатие в панели: хранилище → правка хранилища; стандартная папка → экран «Стандартные папки»; закладка → диалог «Папка в закладках» (имя, путь, удалить).

## Диалоги

Для каждого диалога, кроме отдельных пунктов: поворот экрана — диалог и введённый текст сохранены; светлая и тёмная тема; «Отмена», «Назад» и тап вне диалога — закрыть без действия.

74. «+» → «Файл» / «Папка» → диалог имени: поле в фокусе, клавиатура открыта; ОК при пустом имени → ошибка «пустое имя», с `/` → «недопустимое имя», существующее → «уже существует» (46); правильное имя → создано (45).
75. Меню файла → «Переименовать»: имя подставлено, выделено без расширения; те же ошибки, что в 74; ОК → файл переименован, список обновлён.
76. «Архивировать» (меню файла или панель выделения): имя архива, тип — ZIP, TAR.XZ, 7z; поле пароля — только для ZIP; ОК → архив создаётся в текущей папке в фоне, выделение снято.
77. «Удалить» (меню файла или панель выделения): текст называет файл или папку, для нескольких — их число; ОК → удалено; «Отмена» — ничего не удалено, выделение осталось.
78. Меню → «Перейти к…»: текущий путь в поле; пустой путь → ошибка «пустой путь», недопустимый → «недопустимый путь»; верный → переход (7).
79. Тап по APK при настройке «Действие для APK» = «Спрашивать»: «Установить» → установщик Android; «Просмотр» → APK открыт как архив; «Отмена» — ничего (42).
80. «Открыть с помощью» → «Открыть как…» (своя Activity поверх экрана): заголовок с именем файла, список типов (текст, картинка, аудио, видео, папка, любой) → файл открывается выбранным типом.
81. Режим «Сохранить как», существующее имя (57, 58): «Заменить «<имя>»?» → ОК — файл заменён и экран закрыт; «Отмена» — остаётся экран.
82. Меню файла → «Свойства»: заголовок с именем, вкладки по типу файла (основное, права, контрольные суммы; картинка, аудио, видео, APK — для своих типов). На вкладке прав — диалоги владельца, группы, режима `rwx`, контекста SELinux (с root); у APK — список разрешений. ОК закрывает.
83. Разрешения: объяснение доступа ко всем файлам (Android 11+, 61); доступ к хранилищу (до Android 11) и уведомления (Android 13+, 62); при постоянном отказе — диалог с кнопкой «Открыть настройки» → системные настройки приложения.
84. Боковая панель → «Добавить хранилище…» (своя Activity): список типов (внешнее хранилище, FTP, SFTP, SMB, WebDAV, Android/data, Android/obb) → открывается соответствующий экран.
85. Фоновые операции (свои Activity, видны поверх главного экрана): вставка поверх существующего файла → диалог конфликта «Заменить» / «Объединить» (папки), «Пропустить», «Отмена», новое имя, «Для всех»; ошибка операции → диалог ошибки; архив с паролем → запрос пароля.
