# Security Policy

## Supported Versions

Only the latest version of mftlrs is supported with security updates.

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub: the "Security" tab of this repository → "Report a vulnerability". Do not open a public issue for security problems.

mftlrs is a fork of Material Files. Vulnerabilities found in mftlrs should be reported here, not to the Material Files author, unless you have confirmed that they also affect the original Material Files app.
