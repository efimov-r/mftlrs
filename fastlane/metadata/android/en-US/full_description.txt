An open source file manager, based on Material Files by Hai Zhang.

Features:
- Open source: Lightweight, clean and secure, without analytics.
- Breadcrumbs: Navigate in the filesystem with ease.
- Root support: View and manage files with root access, or via Shizuku.
- Archive support: View, extract and create common compressed files.
- NAS support: View and manage files on FTP, SFTP, SMB and WebDAV servers.
- Themes: Customizable UI colors, plus night mode with optional true black.
- Linux-aware: Knows symbolic links, file permissions and SELinux context.
- Robust: Uses Linux system calls under the hood, not yet another ls parser.

mftlrs is an independent fork and is not affiliated with the Material Files project.
Material Files: https://github.com/zhanghai/MaterialFiles
